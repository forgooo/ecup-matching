# Атрибуты по категориям: разведка

Замер от 21 августа 2026. Три источника: полный каталог `items.parquet` (13 397 761
товар, скан с дедупликацией ключей на товар), человеческий срез `items_human.parquet`
(711 304), и 365 654 размеченные пары для различающей силы.

**Как считается lift.** Среди пар, где ключ есть у обоих товаров:
`P(матч | значения совпали) / P(матч | значения различаются)`. Считается только
при ≥30 парах с каждой стороны, иначе прочерк.

⚠️ Для ключей вроде `страна` lift почти не считается: стороны пары приходят из
**разных схем атрибутов**, и пар, где один и тот же ИСХОДНЫЙ ключ есть у обоих,
почти нет (`страна-изготовитель` есть у 40% товаров, а пар с ним у обоих — 2).
Именно поэтому склейка синонимов обязательна, а приоритет источника пришлось
мерить иначе — через совпадение с партнёром.
