# Матчинг товаров — cross-encoder

**Лучший результат: лидерборд 0.52182** (`solution_syn` в истории экспериментов) —
cross-encoder (568M, `BAAI/bge-reranker-v2-m3`), без ансамблей и ручных признаков,
плюс препроцессинг с приоритетом источника при коллизии синонимов атрибутов.

Сводка экспериментов с числами — [`docs/RESULTS.md`](docs/RESULTS.md).

## Структура

```
inference/          точка входа сабмита (запускается в Docker без интернета)
  run.py             CLI: читает пары + каталог, пишет csv id1,id2,predict
  src/preprocess.py  сборка текста товара из name+attributes — единственный
                     источник признаков, ядро решения
  src/inference.py   обёртка над CrossEncoder
  metadata.json      точка входа для раннера соревнования

train/              обучение (запускалось на отдельной GPU-ноде)
  train_ce.py        базовое обучение на человеческих парах (v1)
  train_llm.py       предобучение на синтетических LLM-парах поверх v1
  train_scale.py     финальный рецепт: 1.5M LLM-пар + replay human:LLM 1:1 — это
                     и есть веса лучшего сабмита
  verify.py          сквозная проверка: упакованный run.py должен воспроизводить
                     метрику обучения

docs/                полная документация
notebooks/           разведочный анализ данных (качество атрибутов, разметки,
                     эксперимент с bi-encoder эмбеддингами — ветка не вошла в решение)
```
